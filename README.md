# SkilledCA Knowledge Hub

![Status](https://img.shields.io/badge/Status-Active-success)
![Tech Stack](https://img.shields.io/badge/Stack-HTML%20%7C%20CSS%20%7C%20JS%20%7C%20Python-blue)

**SkilledCA** is a comprehensive dual-domain platform designed to bridge the gap between **Chartered Accountancy (CA)** and **Technology**. It serves as a central hub for professionals and learners to access high-quality tutorials, tools, and resources.

## 🚀 Project Overview

The website is divided into two main pillars:

### 1. 💻 Tech Hub
Focused on upskilling professionals in modern technology.
*   **Python Scripting**: From zero to automation hero (Beginner/Intermediate/Advanced).
*   **Web Development**: Basics of HTML, CSS, and deployment.
*   **Linux & Security**: Essential command-line tools and cybersecurity practices.
*   **Interactive Learning**: Quizzes and dynamic content.

### 2. 📊 CA Hub
Dedicated resources for finance and audit professionals.
*   **SAP Resources**: Guides on T-Codes, Rectification, and Reversals.
*   **Excel Mastery**: Shortcuts, automation scripts, and Power Query tips.
*   **Tools**: Custom Python scripts for Excel consolidation and data processing.

## 📂 Project Structure

```bash
skilledca/
├── assets/          # Images, Icons (Favicon), and static media
├── ca/              # CA Hub pages (Excel, SAP, Audit tools)
├── tech/            # Tech Hub pages (Python, Linux, Web)
├── forms/           # Feedback and contact forms
├── scripts/         # JavaScript logic (Download system, dynamic content)
├── styles/          # Global CSS (Glassmorphism design system)
├── index.html       # Landing Page
├── SITE_BLUEPRINT.md # Detailed architectural documentation
└── PROJECT_HISTORY.md # Chronological log of changes
```

## ✨ Key Features

*   **Glassmorphism UI**: A premium, modern dark-mode interface with neon accents.
*   **Dynamic Content Loading**: JavaScript-driven tutorial sections for optimized loading.
*   **Lead Capture & Downloads**: Integrated system to capture user details before allowing downloads (e.g., PDF cheatsheets).
*   **Feedback Integration**: Custom forms connected directly to Google Sheets for real-time feedback collection.

## 🛠️ Setup & Installation

To run this project locally:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-username/skilledsite.git
    ```
2.  **Open the project folder**:
    ```bash
    cd skilledsite
    ```
3.  **Run with Live Server**:
    *   If using VS Code, install the "Live Server" extension.
    *   Right-click `index.html` and select **"Open with Live Server"**.
