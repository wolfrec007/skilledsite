📝 Essential Formulas Reference
VLOOKUP / XLOOKUP
=VLOOKUP(lookup_value, table_array, col_index, [range_lookup])
=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found])
Look up values in a table. XLOOKUP is more flexible and recommended for newer Excel versions.
INDEX-MATCH (Pro Combo)
=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))
More powerful than VLOOKUP - can look left, handles insertions/deletions better.
SUMIFS / COUNTIFS
=SUMIFS(sum_range, criteria_range1, criteria1, [criteria_range2, criteria2]...)
=COUNTIFS(criteria_range1, criteria1, [criteria_range2, criteria2]...)
Sum or count cells that meet multiple conditions.
MAXIFS / MINIFS
=MAXIFS(max_range, criteria_range1, criteria1, [criteria_range2, criteria2]...)
Find maximum/minimum values that meet criteria.
IFERROR (Error Handling)
=IFERROR(INDEX(range, MATCH(value, lookup, 0)), "Not Found")
Wrap formulas to handle errors gracefully instead of showing #N/A or #REF! errors.
AGGREGATE (Advanced)
=AGGREGATE(function_num, options, array)
Powerful function that can ignore errors and hidden rows. Function 14 = LARGE, 15 = SMALL, 4 = MAX, 5 = MIN.
